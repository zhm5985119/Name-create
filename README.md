# 诗词八字起名 · 手机版

结合出生时间（八字五行、喜用神、生肖）、三才五格和典籍出处给孩子起名的网页应用。所有计算都在手机或电脑本地完成，不上传任何信息。

- 打开：<https://zhm5985119.github.io/Name-create/>
- iPhone：用 Safari 打开上面的网址 → 点底部“分享” → “添加到主屏幕”。第一次打开需要联网，之后断网也能用。
- 安卓：用 Chrome 打开 → 菜单 → “添加到主屏幕”或“安装应用”。

内容：排八字、五行旺衰、喜用神、生肖喜忌、五格三才、典故名与诗词出处、精选好名、重名参考、读音试听、收藏对比、导出报告。

八字五行、五格数理、生肖喜忌均为传统民俗说法，仅供参考。典籍文本来自公有领域；重名统计基于公开的中文人名语料。
